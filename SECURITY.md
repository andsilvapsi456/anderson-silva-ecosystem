## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

### How to Report

1. Send an email to the repository owner with the subject line: `[SECURITY] Vulnerability Report - anderson-silva-ecosystem`
2. 2. Include a detailed description of the vulnerability
   3. 3. Include steps to reproduce the issue
      4. 4. Include any relevant screenshots or logs
         5. 5. Indicate the potential impact of the vulnerability
           
            6. ### What to Expect
           
            7. - **Acknowledgement**: You will receive a response within 48 hours confirming receipt of your report.
               - - **Assessment**: We will investigate and assess the severity of the vulnerability within 7 days.
                 - - **Resolution**: We aim to release a fix within 30 days for critical vulnerabilities.
                   - - **Disclosure**: We will coordinate with you on responsible disclosure before any public announcement.
